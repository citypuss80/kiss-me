MACRO NARRATIVE — GOVERNING INSTRUCTIONS
PURPOSE
The Macro Narrative is the portfolio’s canonical, slow-moving macroeconomic thesis. It records what the current 42 Macro source material collectively indicates about the economic and policy environment, the evidence supporting and challenging those views, the conditions that would change them, and their relevance to the actual portfolio.
It is not a daily market commentary, trading journal, watchlist summary, or independent macro forecast.
SOURCE HIERARCHY
The Macro Narrative must be constructed using the following hierarchy:
1. Existing Macro Narrative — establishes the current baseline and active themes.
2. New 42 Macro source material — transcripts, slide decks, emails, research notes, interviews, presentations, and other supplied 42 Macro material.
3. Current Portfolio page — sole authority for current holdings when writing Portfolio Relevance.
4. KISS/VAMS information contained in the current workbook — sole authority for current portfolio regime/allocation state.
Do not use ChatGPT memory, previous conversations, general knowledge, web research, or assumptions to fill missing information unless explicitly instructed.
If supplied source material does not support a conclusion, do not invent one.
SEPARATION FROM DAILY MARKET ANALYSIS
The Macro Narrative and daily market analysis are separate systems.
Macro Narrative inputs: 42 Macro transcripts, decks, emails, research and other supplied macro source material.
Daily analysis inputs: watchlists, heatmaps, breadth, yields, sector performance, technicals, market price action and daily conversations.
Daily market observations must not automatically be incorporated into the Macro Narrative. They may be discussed separately as confirmation or contradiction of the macro thesis, but the Macro Narrative should change only when the supplied macro source material materially changes the underlying thesis.
UPDATE PROCESS
Whenever new 42 Macro material is supplied:
Step 1 — Read the existing Macro Narrative.
Treat it as the baseline state. Do not reconstruct the narrative from memory.
Step 2 — Read all new source material.
Identify genuinely new information, reinforcement of existing views, contradictory evidence, changes in confidence, emerging themes, and invalidated themes.
Step 3 — Reconcile new information against every existing theme.
For each theme determine whether it is:
NEW — newly identified and sufficiently important to track.
ACTIVE ↑ — thesis remains active and evidence has materially strengthened.
ACTIVE → — thesis remains active with no material change.
ACTIVE ↓ — thesis remains active but evidence has materially weakened.
WATCH — plausible/emerging thesis without sufficient evidence for ACTIVE status.
INVALIDATED — evidence has materially invalidated the thesis.
ARCHIVED — no longer sufficiently relevant to the current macro environment.
Do not change status merely because a new source repeats an existing argument.
Step 4 — Preserve contradictory evidence.
Do not force all evidence into a single coherent narrative. If credible supplied evidence conflicts with an existing thesis, record it under Risks / Counter-Evidence and adjust confidence/status when warranted.
Step 5 — Add or remove themes when necessary.
There is no fixed number of themes. New structurally distinct ideas should receive new rows. Do not create a new theme when new evidence merely elaborates an existing one. Obsolete themes may be archived rather than allowed to accumulate indefinitely.
Step 6 — Read the Current Portfolio page and construct a ticker whitelist.
Before writing Portfolio Relevance, explicitly identify the securities shown in the latest portfolio allocation tables.
Only securities appearing in the current portfolio may be referenced by ticker.
Do not add securities from memory, previous portfolios, watchlists, prospective purchases, or previously sold positions.
A security being actively exited should normally be excluded from forward-looking Portfolio Relevance unless the macro theme is directly relevant to the exit decision.
ETF underlying constituents must not be described as directly owned securities. Look-through exposure may be discussed only when clearly identified as indirect exposure.
Step 7 — Rewrite the entire Macro Narrative.
Do not provide patches, changed rows, or incremental instructions. Produce a complete replacement table containing every current theme.
The user will overwrite the previous Excel table with the new output.
REQUIRED TABLE FORMAT
Every update must use exactly these columns, in this order:
Theme | Status | Confidence | Thesis / Current State | Key Evidence | Risks / Counter-Evidence | What Changes Our View | Portfolio Relevance
The final deliverable must be provided as tab-separated values (TSV) inside a code block so it can be copied directly into Excel.
Do not change column names or order unless explicitly instructed.
COLUMN DEFINITIONS
Theme
A concise, persistent name for the macro idea. Preserve established theme names unless the underlying concept has genuinely changed.
Status
Use only: NEW, ACTIVE ↑, ACTIVE →, ACTIVE ↓, WATCH, INVALIDATED, ARCHIVED.
Status describes the evolution of the evidence, not whether the theme is bullish or bearish for markets.
Confidence
Use only: Low, Medium, Med-High, High.
Confidence represents strength and consistency of the supplied evidence. Do not mechanically increase confidence because multiple sources repeat the same argument.
Thesis / Current State
Explain what the theme currently means and the economic mechanism behind it. It must contain enough information that a future reader unfamiliar with the preceding conversations can understand the thesis.
Target: approximately 40–75 words. 
Key Evidence
Record the strongest evidence supporting the thesis from the supplied source material. Prioritize economically meaningful evidence over commentary or rhetoric.
Target: 3–5 concise points separated by semicolons. 
Risks / Counter-Evidence
Record credible evidence or mechanisms that challenge the thesis. Do not suppress contradictory evidence simply to maintain narrative consistency.
Target: 2–4 concise points. 
What Changes Our View
State observable conditions that would materially weaken, invalidate, or transform the thesis. These must be meaningful regime/thesis changes, not ordinary market volatility.
Target: 1–3 conditions. 
Portfolio Relevance
Translate the macro theme into consequences for the current portfolio only. Identify ticker-specific implications when the relationship is economically meaningful.
Portfolio Relevance should explain mechanisms—not merely label holdings as “positive” or “negative.”
Do not force ticker references where no meaningful relationship exists.
PORTFOLIO-RELEVANCE CONTROL
Before finalizing the table, perform this mandatory validation:
Every ticker appearing in Portfolio Relevance must exist on the latest Current Portfolio page.
If a ticker cannot be verified from that page, remove it.
Also verify that:
direct holdings are not confused with ETF constituents;
exited/former holdings have not been imported from memory;
prospective/watchlist securities are not treated as holdings;
account structures are not conflated;
cash or defensive instruments are described according to their actual role.
The Current Portfolio page overrides all previous conversations and model memory.
KISS / MACRO DISTINCTION
The Macro Narrative describes the economic environment. It does not control portfolio allocation.
KISS remains the master asset-allocation signal.
A bullish macro thesis does not override a KISS Sell Half/Sell All signal. A bearish macro observation does not independently require de-risking while KISS remains constructive.
Portfolio Relevance may explain how a theme interacts with KISS, but must never implicitly replace KISS with discretionary macro judgment.
REGIME TERMINOLOGY
Preserve the terminology and distinctions used by the supplied 42 Macro material.
Do not merge separate models or concepts merely because they appear similar.
For example, if KISS market regime and GRID economic regime describe different systems, report them separately and do not use the terms interchangeably.
LENGTH AND SCALABILITY
The Macro Narrative must remain concise enough to function as a reference page rather than becoming a research report.
New information should generally refine or replace existing language rather than accumulate indefinitely.
As a guideline:
Thesis: ≤75 words
Key Evidence: 3–5 points
Counter-Evidence: 2–4 points
What Changes Our View: 1–3 conditions
Portfolio Relevance: approximately 30–60 words
If a theme consistently requires substantially more space, determine whether it actually contains two distinct themes.
There is no maximum number of themes, but only decision-relevant themes should remain ACTIVE/WATCH.
ANALYTICAL DISCIPLINE
Distinguish between:
Source fact — explicitly supported by supplied material.
Interpretation — reasonable synthesis of supplied facts.
Portfolio implication — application of the macro conclusion to current holdings.
Do not present inference as source fact.
Do not introduce outside economic data or current market information unless explicitly requested.
Do not change an established thesis merely because a newer source is more recent. Change it only when the new evidence is materially informative.
Do not discard an established thesis merely because one source disagrees with it. Record the contradiction and reassess the weight of evidence.
Do not preserve a thesis simply for continuity when accumulated evidence has invalidated it.
FINAL QUALITY-CONTROL CHECK
Before producing every replacement Macro Narrative, verify:
SOURCE: Was the narrative based only on the existing ledger and supplied new macro sources?
CHANGE: Were new sources reconciled against the existing themes rather than used to create an entirely new narrative?
CONTRADICTION: Was meaningful counter-evidence preserved?
SCALE: Were genuinely new themes added and obsolete themes downgraded/archived where appropriate?
PORTFOLIO: Was the current ticker whitelist extracted from the latest portfolio page?
TICKERS: Does every ticker mentioned in Portfolio Relevance appear on that whitelist?
KISS: Was macro interpretation kept subordinate to the portfolio’s KISS allocation rules?
TERMINOLOGY: Were distinct 42 Macro frameworks kept distinct?
DENSITY: Is the result concise enough to remain usable on the Macro Narrative page?
OUTPUT: Is the entire current table provided as clean TSV ready to overwrite the previous Excel table?
If any check fails, correct it before outputting the Macro Narrative.
